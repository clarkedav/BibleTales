# Overview

As a software developer, I wanted to deepen my skills in game development, event driven programming, and building interactive software with a Python game library. BibleTales is a Bible adventure game where the player walks a roadmap of Bible stories and memory verses, answering questions against a countdown timer. It is designed to send people back to their own Bible.

The journey has two sections, each with its own roadmap:

* Bible Stories: 18 stages, from Creation to the early church and Paul. Each stage starts with a short story and a lesson told by Eli, the on screen guide, followed by quiz questions.
* Memory Verses: 9 stages, from Genesis to Revelation. The player completes well known verses (King James Version) by choosing the missing words.

After every two Bible stories, one Memory Verse stage opens. Only the current stage and finished stages can be played, and the rest stay locked behind a padlock. Finished stages can be replayed in practice mode with no lives lost.

When a player misses a question, the game does not show the answer. Eli sends them to read a whole Bible chapter, such as Genesis 6, and then come back and try again. Every missed chapter is added to a study list that is shown at the end of the game.

Other features:

* Levels that get harder, because the time allowed per question shrinks as the journey goes on
* 3 lives for the whole journey, with a bonus life for a stage finished without mistakes
* Moving objects: a traveller who walks the map, drifting clouds, and confetti
* Eli, an animated 2D guide drawn with code, who talks with a typing effect
* Original sound effects and background music generated by a Python script (press M to turn the music on or off)
* Mouse and keyboard controls

Controls: click or press 1 to 4 to answer, ENTER or SPACE to continue, LEFT and RIGHT to move between stages on the map, TAB to switch between the two roadmaps, and M to toggle the music.

How to run:

1. Install Python 3 and the Arcade library with `python -m pip install arcade`
2. Download or clone this repository
3. In the project folder, run `python main.py`

If the sounds folder is missing, run `python make_sounds.py` first to create it.

My purpose for creating this software was to practice the core parts of a game (a game loop, several screens, moving sprites, input handling, scoring, and a difficulty system) while building something that encourages people to read and memorize Scripture.

# Development Environment

I developed the game in Visual Studio Code on Windows, using Git and GitHub for version control. The game is written in Python 3 and uses the Arcade library (version 3.x) for graphics, sprites, sound, input, and the game loop. All other visuals, including the guide character, the maps, and the icons, are drawn with Arcade's shape functions, and the sound effects and music are generated with Python's standard library.

Project files:

* main.py: the game screens (menu, map, story, quiz, result) and the game loop
* ui.py: shared colors, drawing helpers, and confetti
* guide.py: Eli the guide and the typing speech bubble
* audio.py: loads and plays the sound effects and music
* make_sounds.py: creates the sound files
* questions.py: the original Bible story stages and questions
* extra_questions.py: reading hints, extra questions, and new story stages
* memory_verses.py: the nine memory verse sets
